# 现场验收清单

本项目的协议来自厂商客户端库分析，开发期间没有真机。以下内容必须在真实控制器上确认，全部通过后才能用于生产。

所有步骤都是只读操作，不会改动机床状态。

## 1. 前置条件

- [ ] 控制器已安装 `LynucRemoteEnv2.6.2.0.gsi` 或更新版本（`客户端库文件/LYNUC 远程通讯接口说明.md`）
- [ ] 采集服务器能 ping 通控制器
- [ ] 采集服务器到控制器 TCP 4011 放行

```bash
nc -vz <控制器IP> 4011
```

## 2. 运行探测工具

```bash
node ~/.node-red/node_modules/node-red-contrib-lynuc-cnc/tools/probe.js <控制器IP> --report probe-report.json
```

Node-RED 运行在容器里时，在容器内执行，路径按实际安装位置调整。

把 `probe-report.json` 发回开发侧。里面有每个点位的值和前 300 条原始响应，用来核对下面的未验证项。

## 3. 协议假设核对

| # | 假设 | 判定方法 | 如果不成立 |
| --- | --- | --- | --- |
| A1 | 不做 FTP 登录也能访问 4011 | 探测工具能连上且读到数据 | 需要补 FTP 握手 |
| A2 | 响应格式为 `<码+1><内容>[(回显)]` | 报告 `raw` 字段 | 调整 `lib/client.js` 解析 |
| A3 | 响应是否 NUL 结尾 | 报告 `raw`。全部无 NUL 时每次请求多等 5 ms，一轮约多 0.2~0.3 s | 可接受，或按实际格式优化 |
| A4 | 心跳 `0000` 有响应 | 空闲连接保持 5 分钟不断开 | 调整心跳处理 |
| A5 | `0105`、`0123` 在该版本服务端可用 | `axes.*.load`、`production.cycleTarget`、`program.line` 不失败 | 升级服务端，或换 `0007` |
| A6 | 中文编码 | 用中文文件名的程序和中文报警验证 | 调整解码 |
| A7 | 第 2 通道变量 +100000 | 双通道机床用 `--channel 2` 对比屏幕 | 调整 `lib/points.js` 的 `ch()` |
| A8 | 连接数限制 | 同时开厂商软件和本节点 | 记录上限 |

## 4. 数据核对

把机床置于下列工况，对比探测结果或 Node-RED 输出与控制器屏幕。

| 工况 | 核对项 | 通过 |
| --- | --- | --- |
| 依次切到 AUTO、MDI、JOG、手轮、回零 | `modeRaw` 与 `MODES` 映射一致 | [ ] |
| 运行 / 暂停 / 复位 / 报警停止 | `state`、`running`、`holding`、`stopped` | [ ] |
| 按下急停 | `emergencyStop`、`state=EMERGENCY` | [ ] |
| 手动移动各轴 | `position`、`relative`、`machine` 与屏幕一致（`position` 用 `#B+18`，含刀补的屏幕值在 `#B+26`） | [ ] |
| 主轴正转 / 反转 / 停止 | `spindle.state`、`stateRaw`、转速 | [ ] |
| 改进给倍率、主轴倍率 | `override` 是否为百分比 | [ ] |
| 切削运行中 | `feedrate.actual` 单位是否 mm/min；`velocity` 单位 | [ ] |
| 运行程序 | `program.name`、`line`、`totalLines`、`progress` | [ ] |
| 完成一件 | `completed`、`total`、`partCompleted` 事件 | [ ] |
| 换刀 | `tool.number`、`toolChanged` 事件；刀补值 | [ ] |
| 触发一个可恢复报警 | `alarms` 内容、编码、`alarmRaised` / `alarmCleared` | [ ] |

## 5. 机床差异项

- [ ] 门开关：确认 PLC 或 X 点地址，配置为自定义点位
- [ ] 主轴负载：确认是否占用轴槽，配置为自定义点位
- [ ] 轴配置：`axes` 与实机一致

## 6. 稳定性与性能

| 项目 | 方法 | 标准 | 通过 |
| --- | --- | --- | --- |
| 延迟 | 探测工具汇总的"全量一轮" | 单点平均明显小于 2 ms | [ ] |
| 控制器负载 | 1 s 周期运行时观察控制器系统负载和加工 | 无报警、无卡顿 | [ ] |
| 断线恢复 | 拔网线 1 分钟后恢复 | 自动重连，无需人工干预 | [ ] |
| 控制器重启 | 重启控制器 | 自动恢复 | [ ] |
| 连续运行 | 运行 72 小时 | 无内存增长、无重连风暴 | [ ] |
