## 接口详细说明

### remote_new_connect
- **接口声明:** `int remote_new_connect(const char* iP)`
- **接口描述:** 创建一个新的 TCP 连接
- **可能的返回值:** 大于等于 0 整数（作为句柄），-1， -3， -4
- **参数说明:** `iP`:以“.”分隔的 ip 地址
- **使用说明:** 与控制器建立连接，调用当前库中的接口前使用，返回句柄值用于后续调用其他接口

### remote_close
- **接口声明:** `void remote_close(int nHandle)`
- **接口描述:** 关闭 TCP 连接
- **可能的返回值:** 无
- **参数说明:** `nHandle`:要关闭的连接句柄
- **使用说明:** 与控制器建立连接后， 不需要继续使用该连接，只用次接口关闭连接释放资源

### remote_read_macro
- **接口声明:** `double remote_read_macro(int nHandle, int nMacro)`
- **接口描述:** 读宏变量
- **可能的返回值:** 宏变量值，如果失败会返回 0
- **参数说明:** `nHandle`:连接句柄 `nMacro`:宏变量地址
- **使用说明:** 输入句柄和宏变量地址，返回宏变量值

### remote_read_macro_p
- **接口声明:** `int remote_read_macro_p(int nHandle, int nMacro, double* val)`
- **接口描述:** 返回是否读取成功的读宏变量接口
- **可能的返回值:** 0，-2，-5，-6，-7
- **参数说明:** `nHandle`:句柄 `nMacro`:宏变量号 `val`:读取的数据存放位置
- **使用说明:** 输入句柄、宏变量地址、宏变量存储位置，宏变量值存在传入的指针指向的地址，返回调用是否成功

### remote_write_macro
- **接口声明:** `int remote_write_macro(int nHandle, int nMacro, double val)`
- **接口描述:** 写宏变量
- **可能的返回值:** 0，-2，-5，-6，-7
- **参数说明:** `nHandle`:句柄 `nMacro`:宏变量号 `val`:要写入宏变量的值
- **使用说明:** 将目标值写入宏变量地址

### remote_open_file
- **接口声明:** `int remote_open_file(int nHandle, int nChannel, const char* chFileName)`
- **接口描述:** 远程打开控制器端指定文件
- **可能的返回值:** 0， -1，-2，-6，-7，-8
- **参数说明:** `nHandle`:句柄 `nChannel`:当前通道号（通道一：1 通道二：2） `chFileName`:要远程打开文件的文件名，’\0’结尾
- **使用说明:** 要求在自动模式下、非加工、暂停状态，在控制器端加工模块加载 NC，此函数为异步函数，返回成功后，不要立刻查验是否加载成功，要等待一段时间才有效

### remote_get_open_file_name
- **接口声明:** `int remote_get_open_file_name(int nHandle, char* chFileName)`
- **接口描述:** 获取控制器端打开的当前文件的文件名（不带路径）
- **可能的返回值:** 0，-1，-2，-6，-7
- **参数说明:** `nHandle`:句柄 `chFileName`:存储获取到的文件名
- **使用说明:** 获取控制器端通道一打开的当前文件的文件名，仅文件名不带路径

### remote_get_open_file_path
- **接口声明:** `int remote_get_open_file_path(int nHandle, char* chFilePath)`
- **接口描述:** 获取控制器端打开的当前文件的文件名（带相对路径，例如：NC1/A1.NC）
- **可能的返回值:** 0，-1，-2，-6，-7
- **参数说明:** `nHandle`:句柄 `chFileName`:存储获取到的文件名
- **使用说明:** 获取控制器端通道一打开的当前文件的完整文件名（带路径）

### remote_get_file_last_modified_time
- **接口声明:** `int remote_get_file_last_modified_time(int nHandle, const char* chFilePath, int* nLastModifiedTime)`
- **接口描述:** 获取控制器端文件最后修改时间
- **可能的返回值:** 0，-1，-2，-6，-7
- **参数说明:** `nHandle`:句柄 `chFilePath`:文件路径 `nLastModifiedTime`:最后修改时间(UNIX 时间戳)
- **使用说明:** 文件路径为文件在控制器上的完整路径，获取的时间为 UNIX 时间戳，可用于比较文件是否更新（示例：/home/....../NC1/）

### remote_get_exe_file_md5sum
- **接口声明:** `int remote_get_exe_file_md5sum(int nHandle, int nPath, char *buf)`
- **接口描述:** 获取控制器端打开的当前文件的 md5
- **可能的返回值:** 0，-1，-2，-6，-7
- **参数说明:** `nHandle`:句柄 `nPath`:通道号 `buf`:存储获取到的 md5
- **使用说明:** 用于和本地文件比较，测试文件是否相同

### remote_set_receive_timeout
- **接口声明:** `int remote_set_receive_timeout(int nHandle, int nMillisecond)`
- **接口描述:** 设定除 ftp 相关接口以外接口（宏变量读写等）的 socket 接收超时时间
- **可能的返回值:** 0，-2
- **参数说明:** `nHandle`:句柄 `nMillisecond`:超时时间(ms)
- **使用说明:** 默认超时时间和平台相关，此处可以设定超时时间，防止网络不通时接口长时间不能返回

### remote_set_send_timeout
- **接口声明:** `int remote_set_send_timeout(int nHandle, int nMillisecond)`
- **接口描述:** 设定除 ftp 相关接口以外接口（宏变量读写等）的 socket 发送超时时间
- **可能的返回值:** 0，-2
- **参数说明:** `nHandle`:句柄 `nMillisecond`:超时时间(ms)
- **使用说明:** 默认超时时间和平台相关，此处可以设定超时时间，防止网络不通时接口长时间不能返回

### remote_get_errormessage
- **接口声明:** `int remote_get_errormessage(int nHandle, char* errormessage);`
- **接口描述:** 获取错误信息，格式：【1204】错误信息一_L2-【1011】错误信息二_L1-【1001】错误信息三_L3

- **可能的返回值:** 0：已连接返回 -1：无错误 -2：未建立连接 -6:发送失败 -7：接收失败
- **参数说明:** `nHandle`:句柄， `errormessage`:存储错误信息
- **使用说明:** 参数 2 ：C#语言调用接口需要使用 stringbuilder 类型

## 调用示例

### C++篇：
```cpp
int handle = remote_new_connect(“127.0.0.1”);
double value = 0;
//读取宏变量 100 的值
int readstate = remote_read_macro_p(handle, 100, &value);
//读取宏变量 100 的值
value = remote_read_macro(handle, 100);
//向宏变量 100 写入值
readstate = remote_write_macro(handle, 100, value);
//读取 PLC 地址为 MOU31.25.28 的值
unsigned long PLCVal = remote_read_plc_variable(handle, 1, “31.25.28”);
//向 plc 地址为 MOU31.25.28 的变量写 1
readstate = remote_write_plc_variable(handle, "31.25.28", 1, 1);
//启动 NC 程序
int status = remote_write_plc_variable(handle, "31.4", 1, 1);
//暂停 NC 程序
status = remote_write_plc_variable(handle, "31.5", 1, 1);
//复位信号，置 1 生效但是需要重新置 0，否则下次复位不生效
status = remote_write_plc_variable(handle, "31.9", 1, 1);
status = remote_write_plc_variable(handle, "31.9", 1, 0);
char strvalue[99];
//获取字符数据
readstate = remote_set_StringMap(handle, "barcode", "1234");
readstate = remote_get_StringMap(handle, "barcode", strvalue);
//获取错误信息
readstate = remote_get_errormessage(handle, strvalue);
char* fileName = "NC1.NC";
char* outputPath = "F:/";
//上传 NC1.NC 文件到控制器 “/home/Lynuc/Users/NCFiles/NC1” 路径下
readstate = remote_upload_file(handle, "E:/NC1.NC", 1001);
//从控制器 “/home/Lynuc/Users/NCFiles/NC1” 路径 下载 NC1.NC 文件
readstate = remote_download_file(handle, 1001, filename , outputPath);
//删除控制器 “/home/Lynuc/Users/NCFiles/NC1” 路径下的 NC1.NC 文件
readstate = remote_delete_file(handle, filename , 1001);
```
